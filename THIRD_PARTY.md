# Компоненты и источники

Собственный код этого репозитория не копирует Wialon, СКАУТ или ГЛОНАССсофт.
Названия этих продуктов используются только для объяснения назначения проекта.

- [Traccar](https://github.com/traccar/traccar), Apache-2.0 — отдельный Docker-образ,
  сервер протоколов, API и штатный интерфейс. Его исходники не включены в репозиторий.
- [React](https://github.com/facebook/react), MIT.
- [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js), BSD-3-Clause.
- [PostgreSQL](https://www.postgresql.org/about/licence/), PostgreSQL License.
- [Nginx](https://nginx.org/LICENSE), BSD-style license.
- Vite, TypeScript, pnpm и транзитивные зависимости сохраняют свои лицензии.
- [OpenStreetMap](https://www.openstreetmap.org/copyright): данные ODbL,
  отдельные правила сервиса тайлов, атрибуция обязательна.

Владелец проекта выбирает лицензию для собственного кода отдельно.
Наличие публичного репозитория само по себе не предоставляет лицензию на этот код.
