# Проверки первой версии

Проверено локально:

- TypeScript: без ошибок.
- Production-сборка Vite: успешна.
- 4 теста координат, единиц скорости, периода и порядка точек: пройдены.
- 3 браузерных сценария Chromium с подменённым API: пройдены.
  Первый администратор; выбор разделов и управление клиентом;
  ограничения интерфейса клиента.
- Конфигурация Traccar XML: синтаксис проверен.
- Генерация случайного пароля базы и отказ перезаписывать существующий .env: проверены.
- Python-скрипты: компиляция без ошибок.

Локально НЕ проверено: запуск Docker Compose, миграции Traccar/PostgreSQL,
реальный приём протокола и серверная изоляция клиентов. В среде разработки
Docker отсутствует. Эти проверки включены в GitHub Actions через
scripts/smoke.py, но результат запуска CI ещё не получен.

Браузерные тесты проверяют собственный интерфейс и не заменяют интеграционный тест.
Перед подключением реального транспорта дождитесь успешного CI и проверьте
конкретную модель трекера на своём сервере.

Сборщик предупреждает о размере JS-пакета карты (около 1,16 МБ до сжатия).
Это не ошибка сборки; разделение загрузки карты можно выполнить при оптимизации.

## Мастер установки

В Ubuntu WSL проверены Bash-синтаксис install.sh, запуск справки, компиляция
Python-скриптов и 13 тестов в tests/test_installer.py. Проверяются адреса и порты,
изоляция начального запуска на loopback, сохранение существующего пароля,
защита пользовательского override, повторный запуск и создание администратора
с подменённым API.

Один тест объединения конфигураций настоящим Docker Compose локально пропущен:
Docker отсутствует и в доступной Ubuntu WSL. В GitHub Actions этот тест запускается.
scripts/smoke.py теперь использует создание администратора из мастера против
реального Traccar и проверяет повторное выполнение без пересоздания пользователя.

Установка пакетов APT/Docker и весь интерактивный процесс на чистой Ubuntu
ещё не запускались. Реальную доступность терминалов из мобильной сети можно
проверить только после развёртывания на целевом сервере и настройки его сети.
